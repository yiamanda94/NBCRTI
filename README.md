# 傳統通路戰情表

北部營業處傳統通路的菸架購貨、啤酒五大陳列、酒特陳架、全品項業績（BW）追蹤頁。

資料檔已用密碼加密（AES-GCM），打開網站需輸入密碼才會顯示。

## 檔案

| 檔案 | 內容 | 來源 Excel |
| --- | --- | --- |
| index.html | 網頁本體 | — |
| data.json | 菸架購貨 | 傳統菸架客戶購貨進度表 |
| beer.json | 啤酒五大陳列 | 啤酒傳統店家商化管理活動購貨進度 |
| liq.json | 酒特陳架店家名單與 Q1–Q3 | 傳統酒類陳列簽約店家購值追蹤 |
| perf.json | 全品項業績、酒特陳架最新一季 | BW-SD9900 銷售萬用報表（2025、2026 工作表） |

## 更新資料

更新工具「戰情表資料檔產生器.html」只放在管理者自己的電腦，不放在這個儲存庫。

1. 在電腦上雙擊打開「戰情表資料檔產生器.html」。
2. 輸入資料密碼（跟網站目前用的同一組），把最新的 Excel 拖進去，確認家數和日期。
3. 按「加密並下載」，會下載加密後的 .json。
4. 到這個儲存庫按 Add file → Upload files，把 .json 拖進去覆蓋同名檔案，按 Commit changes。
5. 約 1 分鐘後網站更新。

## 注意

- 4 個資料檔必須用同一組密碼加密。
- 忘記密碼無法還原，只能用新密碼重新產生全部資料檔。
- 要換密碼：用新密碼重新產生 4 個資料檔並全部上傳覆蓋。
